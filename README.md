# ML Service: Cardiovascular Disease Risk Prediction

Репозиторий содержит реализацию REST API сервиса для оценки вероятности наличия сердечно-сосудистых заболеваний на основе клинических показателей пациента.
## 1. Актуальность проекта

Сердечно-сосудистые заболевания (ССЗ) являются ведущей причиной смерти во всем мире. Раннее выявление факторов риска позволяет своевременно назначить профилактическое лечение и значительно снизить смертность. Автоматизация процесса первичного скрининга с помощью алгоритмов машинного обучения позволяет снизить нагрузку на врачей и предоставить пациентам быстрый инструмент самодиагностики.
## 2. Требования к системе
Функциональные требования

    Регистрация и аутентификация: Безопасный вход пользователей в систему.

    Прогнозирование: Эндпоинт для передачи биометрических данных и получения вероятности наличия ССЗ.

    Интерпретация: Краткое пояснение результата (какие факторы внесли наибольший вклад в риск).

    Дообучение: Возможность загрузки новых размеченных данных для переобучения модели администратором.

Нефункциональные требования

    Скорость отклика: Обработка одного запроса на предсказание не должна превышать 300 мс.

    Безопасность: Использование JWT-токенов для защиты персональных данных.

    Контейнеризация: Полная поддержка Docker для быстрого развертывания.

    Документированность: Автогенерация документации через Swagger (OpenAPI).

3. Архитектура системы

Проект построен на микросервисной архитектуре:

    API Layer (FastAPI): Обработка HTTP-запросов, валидация входных данных с помощью Pydantic.

    Business Logic Layer: Логика обработки данных, проверка прав доступа.

    ML Inference Layer: Загруженная предобученная модель, которая принимает вектор признаков и возвращает результат.

    Data Layer: SQLite для хранения профилей пользователей и истории их запросов.
